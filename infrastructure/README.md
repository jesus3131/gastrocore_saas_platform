# Infrastructure

Esta carpeta concentra todos los recursos de despliegue y operación del sistema.

## Contenido

- docker/: archivos Docker Compose y Dockerfiles para entornos de desarrollo y producción.
- k8s/: manifiestos Kubernetes y configuraciones para orquestación.

## Objetivo

Centralizar la configuración de infraestructura para que el backend, frontend y servicios auxiliares puedan ejecutarse de manera consistente en distintos entornos.
